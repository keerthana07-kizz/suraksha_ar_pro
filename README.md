# 🛡️ Suraksha AI Pro

### Disaster Intelligence + Infrastructure Resilience Dashboard

Suraksha AI Pro is a student-built disaster preparedness and infrastructure resilience web application. It combines disaster scenarios, location context, infrastructure awareness, risk analysis and preparedness actions into a single accessible dashboard.

The project is designed as a prototype to demonstrate how technology can support disaster awareness and emergency preparedness.

---

## ✨ Key Features

- 🌊 Flood, earthquake and cyclone threat scenarios
- 📊 Interactive disaster risk dashboard
- 🎯 Dynamic risk score and risk level
- 📈 7-step risk trajectory visualization
- 🧩 Risk factor breakdown
- 📍 Browser-based location detection
- 🗺️ Interactive OpenStreetMap / Leaflet map
- 🏗️ Nearby infrastructure awareness
- 🚨 Infrastructure risk alerts
- ✅ Emergency preparedness checklist
- 📋 Readiness percentage
- 🏆 Digital preparedness certificate
- 🔐 Cryptographic verification hash
- 📱 Responsive mobile-friendly interface
- 🎨 Modern cinematic product-style UI

---

## 🧠 How It Works

The application allows users to select a disaster scenario and adjust different environmental and preparedness factors.

The system processes these inputs through a Node.js + Express risk engine and generates:

- Overall risk score
- Risk level
- Risk trajectory
- Risk contributing factors
- Infrastructure awareness
- Recommended preparedness actions

The dashboard also uses browser geolocation and OpenStreetMap-based mapping to provide location-aware context.
